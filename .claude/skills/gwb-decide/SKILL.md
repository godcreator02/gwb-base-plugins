# 选型：正本在内核仓

**先读正本**：`D:\unitfolders\26090705ymz\gwb-kernel\.claude\skills\gwb-decide\SKILL.md`

坐在这个仓时它不进上下文，直接 Read 那个路径。触发条件、推导七步、记录格式全在那份里。

## 三句话摘要

1. **不自己拍板。** 推导做得再漂亮，选型也归人。你的活是把选项、依据、代价摆到人看一眼
   就能判的程度。
2. **代价要事实，不要印象。** 去看代码、数行数、跑一次、查 npm 上的状态。「更整齐」不能判，
   「8 张 64KB 的表彼此差不到 6%」能判。
3. **拍板后记进 decisions**。

## 这个仓的差异：记哪儿

选型如果**只关系到件**（某个件用什么库、某个件的接口形状），记进**这个站**的
`decisions` 页——还没建，第一条出现时建。

选型如果关系到**规则**（命名、依赖判据、内核该不该做某事），那是内核仓的事，
记进内核仓的 `decisions.mdx`。

分不清就问：**这条定了之后，别的件要不要跟着改？** 要，就是规则，归内核仓。
