# 定过的事

选型推敲完交给人决定，决定之后记进这一页。只记和**插件**有关的选型；和**规则**有关的（命名、依赖判据、
内核该不该做某件事）记在内核仓的文档站。

条目记「定了什么、为什么」；经过、测量数据与改判的历史写在轨迹卡里，这一页不抄第二份。
**此刻没有待记的条目**——仍然成立的规则写在各自插件的页面上：MCP 工具为什么只有三个、default 的端口为什么不让，
见 [mcp](/docs/mcp)；一键更新为什么是停用再启用、装插件时哪些 peer 装哪些跳过、卸载为什么先删条目后卸包，
见内核仓 gwb-kernel 文档站的 plugin-manager 页（plugin-manager 已于 2026-09-23 搬进内核仓）。三仓拆分的理由在
轨迹卡 `2026-09-12-three-repos-split`，MCP 入口两次交接的理由在轨迹卡「HTTP 门接班」与「MCP 复位」。
