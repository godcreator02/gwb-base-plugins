**本页回答**：设置与凭据存在哪、插件怎样使用、AI 怎样完成配置而不经手明文。包名 `@godcreator/gwb-settings`，入口是 `plugins/settings/src/index.ts`。

每个 home 有自己的 `settings.json` 与 `credentials.json`，不继承 default。前者存普通值、设置声明与分区归属，后者存 secret 的明文值；插件继续声明 `type:'secret'` 并经服务取用。

## 功能

- **按条目分区**：分区是调用方条目 id 的末段；同一个包的两条条目各存各的。`shared:true` 进入当前 home 的公共区 `*`，不跨 home。
- **声明与取值**：`define` 给出 key、title、type 和可选说明、默认值；服务 `get` 先找自己声明的项，没有保存值时回 default；没声明过的 key 去公共区找。普通值由消费方校验，写入 secret 必须是字符串。
- **一组设置**：份数不定、字段相同的配置（如多份模型，每份是模型名、请求地址、token）用 `defineGroup` 声明。组名那一项是 string-list，存实例名单；名单里每个实例的每个字段由设置插件声明成普通设置，键名 `<组>.<实例>.<字段>`，所以现有命令、凭据打码与设置窗格照常列出和读写它们。名单经 `settings.set` 或服务 `set` 改动时先整份校验（字符串数组、每个都是 kebab-case、不重复），不合规整次拒绝；写入后新实例补声明，去掉的实例撤销声明、值留着成为 `live:false` 的项。使用方用时调 `getGroup` 现读，名单变化不发事件。
- **选项**：`define` 可以给 string 型的项配 `options`（回字符串数组的异步函数）。`settings.all` 的这一行带 `hasOptions: true`，设置窗格画成下拉框，清单经 `settings.options` 现取；经 `settings.set` 或服务 `set` 写入时值必须在清单里，不在就整次拒绝，`settings.delete` 不查清单。
- **监听**：服务 `watch(key, listener)` 只收自己声明过的项；这一项写进文件之后（经命令、界面还是自己的 set / delete 都算），回调收到 get 会回的值。写文件失败不通知；回调抛错不影响已写入的值，记一条 warn 写明是哪个条目的回调。调用方卸载时自动注销。
- **按对象选择命令**：`settings.all/get/set/delete` 只处理普通设置；`credentials.list/status` 只查凭据的配置情况。设置命令遇到 secret 会明确报错，不随调用来源改变 get 的返回含义。
- **凭据管理在本机完成**：`credentials.copy`、`credentials.import`、`credentials.generate` 只返回目标状态。目标必须是已启用插件声明的 secret；覆盖已有值要显式 `overwrite:true`。跨 home 复制只读取点名的来源，只写当前 home。本地界面输入与查看分别用隐藏命令 `credentials.set/reveal`，两条均拒绝 MCP 来源。
- **分区归属与声明持续保存**：`settings.json` 顶层 `$owners` 记包名，避免另一包误用旧分区。插件卸载只撤销运行中的声明，文件里的元信息仍可列出，`live:false`。
- **同步读取、排队持久化**：构造时读完两份文件，插件加载时即可同步 `get`；同一服务实例的写操作排队，同一轮 define 合并成一次写文件。日志不记录值。

## 接口

<Diagram name="settings-layout" title="每个 home 的普通设置与凭据，分别经过哪些入口">
- settings.json 保存分区归属、设置声明与普通值；credentials.json 保存对应分区与键的 secret 明文
- 插件服务只给 key，设置插件从调用方条目确定分区；没声明的 key 读当前 home 公共区
- settings.* 只操作普通设置；credentials.* 管凭据，list/status 不回值；插件服务 get 仍可取凭据原文
- credentials.copy/import/generate 在本机保存凭据后只返回状态；显式跨 home 复制后，两边独立配置
</Diagram>

## 依赖

命令总线与说明书服务局部注入；没有命令总线，插件服务仍可使用，只是页面与 agent 没有设置命令。必需的 home 位置取自内核 `gwbKernel.dataDir`。完整接线见[插件之间怎么连](/docs/wiring#godcreatorgwb-settings)。

## 不做的事

- **不加密、不隔离本机代码**：文件是明文，受信插件可内部读取；隐藏回执用于避免日常 AI 流程暴露凭据。
- **不把生成随机值当服务端签发**：有效期、认证和撤销由使用凭据的业务插件负责。
- **不自动跨 home 共享**：必须显式复制；不继承 default，不回退读取其他 home。
- **不承诺两文件事务**：每份文件原子替换，先写凭据再写元信息，删除记录防止中断后旧值复活；损坏文件不覆盖。恢复规则见[设置接缝](/docs/seams/settings)。
- **不画设置界面、不存业务数据**：界面归 UI 插件，其他业务数据归 gwb-data。
