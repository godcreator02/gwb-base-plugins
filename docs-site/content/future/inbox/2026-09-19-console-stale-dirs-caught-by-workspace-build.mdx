* **目标仓**：`D:\unitfolders\26090709qzp\gwb-base-plugins`
* **现场**：隔离 home `wsprobe-2609191048`，`devkit.audit-structure {"root":"D:\\unitfolders"}`（@godcreator/gwb-devkit@0.18.0，2026-09-19 11:06），7 条 error `manifest-missing`：
  * `plugins/baseui`、`plugins/hello`、`plugins/http`、`plugins/shell`、`plugins/theme`、`packages/shared-react`、`packages/tokens`——盘上都在、`package.json` 都不在

* **期望**：删掉这七个盘上残件目录（git 里本来就没有，纯清理）。顺手两条 warn 迁不迁自定：根 yaml 收了 docs-site；九个件包缺 vitest.config.ts / .oxlintrc.json（根共享配置是老仓形状）
* **清完验证**：`devkit.audit-structure {"dir":"D:\\unitfolders\\26090709qzp\\gwb-base-plugins"}` 应只剩 warn
