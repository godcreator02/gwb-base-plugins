### GWB-01 MCP 缺 Host/Origin 校验，回环监听不足以构成网页访问防线（P0｜读码推断：配置与依赖默认值已核验）
* 位置：`plugins/mcp/src/index.ts:267-288,298` @678ce2e；`@godcreator/gwb-mcp@0.9.0/src/index.ts:265-286` 同逻辑
* 现象：只检查路径和 POST 就构造 `StreamableHTTPServerTransport({})`，无应用层 Host/Origin 白名单；SDK 1.30.0 的 `webStandardStreamableHttp.js:79` 默认关闭 DNS rebinding 校验（自动开校验的是本项目未使用的 Express helper）。MCP 传输规范要求验证 Origin；`run` 能到文件、进程、装包能力
* 期望：mcp HTTP 接入层显式校验 Host/Origin；按 home 设计客户端认证与权限边界；对无 Origin 的非浏览器客户端定清晰策略。**不要只换新版 SDK 或只加 CORS 响应头**。涉 MCP 接入契约需拍板；插件同进程同权是另一明确信任前提

### GWB-08 data/settings 并发写复用同毫秒临时文件（P1｜已验证 data 写函数；settings 同型为读码推断）
* 位置：`plugins/data/src/store.ts:32-44`、`plugins/data/src/index.ts:77-85`、`plugins/settings/src/store.ts:38-49`、`plugins/settings/src/index.ts:183-199`
* 现象：临时文件名只有目标名+PID+Date.now，写接口无每目标串行化；并发保存同一文档可能互相改名/清理对方临时文件。CORE-write-collision 固定毫秒并发 12 次记 8 次 ENOENT（构造性重叠，8/12 非生产失败率）。shell 快速布局保存与设置写入确有多路调用
* 期望：每目标唯一临时文件 + 每文档顺序队列，明确后写版本顺序；设置文件统一排队、失败保留待存数据。**data/settings 被 inject 的写入语义若变需拍板**

### GWB-11 settings.all 把所存凭据发到 agent 会话（P1｜已验证纯假秘密）
* 位置：`plugins/settings/src/registry.ts:14,179-180,200-208`、`src/index.ts:91-99`、`skills/gwb-settings/SKILL.md:15`
* 现象：type:secret 只决定 UI 控件掩码；all/read 返回实际 value，设置 skill 又引导先枚举所有设置——本来只供服务调用的秘密被复制进 agent 上下文与会话记录（暴露面风险，非已发生泄露的结论）
* 期望：通用列表返回类型/是否已设置/掩码；实际秘密仅经必要的服务侧访问；独立设计授权的展示/更换操作；OS 凭据存储纳入统一设置层而非各件各做一套。**settings 命令与凭据契约需拍板**

### GWB-13 MCP 透传失败缺 isError，命令行客户端可退出 0（P1｜已验证结果翻译；客户端退出为读码推断）
* 位置：`plugins/mcp/src/tools.ts:46-60,88-97`、`bin/client.mjs:172-183`；0.9.0 同机制
* 现象：普通 `{ok:false,error,data}` 被翻成纯错误文本、data 丢失；带额外字段的失败和 CLI 的 ok:false 回执走 textResult 不置 isError；client 只看 isError 定退出码——业务失败退出 0
* 期望：保留完整结构化结果，失败统一置 isError；客户端按明确业务状态退出、保留 stderr/partial 诊断；不删 CLI 有用字段强求同形。**MCP 回执协议变化需拍板**

### GWB-14 instructions 泛化授予自修改权限，未区分内容可信来源（P1｜已验证文案与回执形状）
* 位置：`plugins/mcp/instructions.md:21-32`、`src/inventory.ts:65-82`、`src/tools.ts:19-20`；0.9.0 instructions 保留同类授权文案
* 现象：instructions 写「不用问就能修 bug、改 SKILL、新增件」——能力说明被当成授权，套用到其他安装者/其他 agent 会误导；文件/论文/笔记正文与命令结果同为 JSON 文本、无来源信任标签
* 期望：instructions 只述能力、约束、如何确认授权，授权来自用户/宿主；对外部正文标来源与数据身份；读写命令有明确操作分类。**MCP/命令元数据契约需拍板**
* 顺带（冷启动表）：最新 instructions 固称机器是 `D:\unitfolders`——unit-folder 未配置根时回 unconfigured 才是正确空态，文案一并改
