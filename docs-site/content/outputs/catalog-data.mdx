# gwb-data

**定位**：插件落盘状态的统一出口——要落盘就用它，不自己拼路径、不碰 fs。

## 提供

`gwbData`：readDoc(doc) / writeDoc(doc, value)（原子落盘），外加 dir（本件那格数据目录）；分家按条目 id 末段，落 `<>`/data/`<>`/
