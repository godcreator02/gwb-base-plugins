# 交接

**本页回答**：现在有什么活正在做、做到哪儿了、交给下一个会话要看什么。

这一区的规矩一句话：**有页 = 有活正在做，做完删**。一件活一页，页头是验收清单，正文是实施方案；
边做边提交，中途每次提交都是一份可交接的快照。做完把结论写回各区——设计进
[现状区](/docs)，决定写进[关键设计](/docs/design)，没做的回[未来区](/future/roadmap)——
然后把那一页删掉。git 历史就是它的存档。这一页本身是导读，不算活。

**此刻没有正在做的活**——这一区只有这一页导读。侧栏上它旁边出现别的页，就是有活正在做。

## 什么样的活才单独写一页

**跨会话、跨模块、有没定的选型**，三条占一条才写 spec；一个会话做得完的直接在插件页上开工。
先把需求边界想清楚，能说清「回答什么 / 不做什么 / 成功标准」；做选型用 `gwb-decide`，
两件事不重叠。
